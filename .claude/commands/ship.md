# /ship

## PLAN

- Read the GitHub issue.
- Search scratchpads for related context.
- Search recent PRs for patterns.
- Identify files to change.
- Produce a step-by-step plan.
- WAIT for approval.

## BUILD

- Create feature branch.
- Implement contracts first.
- Follow GLOBAL_STANDARDS.
- Commit after each logical step.
- Run typecheck and lint.

## TEST

- Run existing tests.
- Add unit tests for logic.
- Add UI tests if needed.
- Ensure all tests pass.

## REVIEW

Check against GLOBAL_STANDARDS:

- SOLID followed?
- No duplication?
- Types explicit?
- Errors handled?
- Components <200 lines?

## PR

- Open PR with GitHub CLI.
- Request review.
